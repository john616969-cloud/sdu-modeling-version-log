# 数模版本站

面向数学建模竞赛团队的极简文件版本网页。成员选择本人姓名并使用对应密码登录，上传论文、代码、数据或图片；系统自动编号并把文件、日志和状态索引作为一次 GitHub 提交保存。

## 功能

- 最新论文主稿和代码包固定展示。
- 上传人、北京时间、修改说明、文件大小和 SHA-256 留档。
- 各类别独立生成 `v001`、`v002` 等连续版本号。
- 并发提交冲突自动重试，不覆盖已有文件。
- 下载任意历史文件，恢复旧文件时创建新的版本。
- 单文件限制 20 MB，密码和 GitHub 令牌只保存在服务端。
- 首次登录后在同一浏览器保持登录 7 天，主动退出会立即清除会话。
- 所有成员可查看下载日志；只有 `PAPER_OWNER` 的管理员页面显示登录日志。
- 登录页面每 5 分钟更新最后活跃时间，10 分钟未更新视为离线；只有管理员页面显示成员在线记录。

## 准备 GitHub 仓库

1. 创建一个私有 GitHub 仓库，并在创建时添加 README，保证 `main` 分支存在。
2. 创建细粒度 Personal Access Token，只授权这个仓库，并只开启 Contents 的读写权限。
3. 不要把令牌、团队密码或会话密钥写进仓库文件。

## 配置成员姓名

在部署环境变量中设置：

```text
TEAM_MEMBERS=张三,李四,王五
PAPER_OWNER=张三
```

`PAPER_OWNER` 使用独立管理员密码，其他成员使用团队密码。它也用于服务端判断谁可以上传或恢复“论文主稿”，以及谁能查看登录日志。

## 生成安全配置

在 `site` 目录运行以下命令生成团队密码哈希：

```powershell
node scripts/generate-password-hash.mjs "你们的团队公共密码"
```

把输出完整填入 `TEAM_PASSWORD_HASH`。再用管理员的独立密码运行一次同样的命令，把第二次输出填入 `ADMIN_PASSWORD_HASH`。最后生成至少 32 字节的随机会话密钥并填入 `SESSION_SECRET`。其余变量参见 `.env.example`。

如需让所有已登录设备立即重新输入密码，请更换 `SESSION_SECRET` 并重新部署。比赛结束后建议执行此操作，同时撤销比赛使用的 GitHub 令牌。

在线记录使用私有 GitHub 仓库存储，每个活跃成员约每 5 分钟产生一次私有提交。同一页面 4 分钟内的重复上报不会重复提交。

## 本地开发

复制 `.env.example` 为 `.env.local`，填入真实配置，然后运行：

```powershell
npm install
npm run dev
```

访问终端显示的本地地址。运行 `npm test` 和 `npm run build` 可执行验证。

## 比赛使用建议

- 论文主稿只由 `PAPER_OWNER` 指定的姓名上传，其他成员上传到“论文修改稿”。
- 修改说明写清“改了什么、为什么改、还需谁处理”，不要只写“最新版”。
- 代码先排除虚拟环境、缓存、密钥和大数据，再打包为 ZIP。
- 超过 20 MB 的文件放团队云盘；在修改说明中记录地址，并另行保存 SHA-256。
- 比赛前用三台电脑演练一次登录、同时上传、下载和恢复。
