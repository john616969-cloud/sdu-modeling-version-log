# 七天自动登录设计

## 目标

成员在一台设备上首次输入正确的团队公共密码后，七天内再次打开版本站时自动进入工作台，不必重复输入密码。

## 行为

- 登录成功后，服务端签发有效期为七天的会话 Cookie。
- Cookie 使用 `HttpOnly`、`Secure`、`SameSite=Strict`，浏览器脚本不能读取。
- 会话内容只包含到期时间，并使用服务端 `SESSION_SECRET` 做 HMAC-SHA256 签名；不保存公共密码、密码哈希或 GitHub 令牌。
- 关闭浏览器、重启电脑或重新打开网址不会清除仍有效的会话。
- 七天从最近一次成功输入密码时开始计算，不因普通访问自动延期。
- 会话到期、签名错误或 `SESSION_SECRET` 变更后，成员重新看到密码登录页。
- 点击“退出登录”立即清除当前设备的会话 Cookie。
- 不提供跨设备同步登录；每台新设备首次使用时都要输入一次公共密码。

## 实现范围

- 将当前十二小时的会话期限改为七天。
- 登录响应沿用现有安全 Cookie，不使用 `localStorage`。
- 在登录页补充“登录后将在此设备保持 7 天”的明确说明。
- 在 README 中记录七天会话和强制全部设备重新登录的方法：更换 `SESSION_SECRET`。

## 错误与安全

- 无效或过期 Cookie 按未登录处理，不返回内部校验细节。
- 自动登录只减少重复输入，不改变 GitHub 接口、成员选择、上传权限和限流规则。
- 公共电脑使用后必须点击退出；比赛结束后应更换 `SESSION_SECRET` 和撤销 GitHub 令牌。

## 验收

- 登录 Cookie 的 `Max-Age` 为 604800 秒。
- 会话载荷到期时间约为签发时间后七天。
- 有效会话可以直接读取版本摘要。
- 过期、损坏或使用旧密钥签发的会话被拒绝。
- 退出响应将 Cookie 的 `Max-Age` 设为 0。
- 页面与文档均说明七天自动登录及公共电脑退出要求。
