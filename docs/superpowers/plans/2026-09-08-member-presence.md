# 成员在线记录实施计划

1. 扩展签名会话载荷，加入服务端随机会话 ID，并补充旧会话失效、签名篡改和多会话测试。
2. 在私有 GitHub 数据层增加在线记录类型、有效记录过滤、4 分钟去重、10 分钟分段、500 条截断、成员汇总和原子提交重试。
3. 新增在线接口：所有有效成员可上报自己的活跃状态；只有管理员可读取在线汇总和历史记录。
4. 在已登录工作台增加首次、每 5 分钟、页面回到前台及网络恢复时的心跳上报，失败时不阻断核心功能。
5. 仅在管理员页面增加成员在线汇总和历史表格，并覆盖加载、空状态和错误状态。
6. 更新说明文档，运行接口权限、时间边界、多电脑汇总、现有回归测试、代码检查、生产构建和敏感信息扫描。
7. 提交并同步源码，打包已验证构建，发布到现有公开网址并检查匿名权限边界。
