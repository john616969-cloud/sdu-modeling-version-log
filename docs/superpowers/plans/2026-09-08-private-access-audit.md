# 私有访问审计日志实施计划

1. 扩展认证模块：支持成员选择、管理员独立密码、带成员与角色的七天签名会话，以及管理员权限校验。
2. 扩展私有 GitHub 数据层：定义审计事件、原子写入 `audit/index.json` 和事件文件、并发重试及管理员读取。
3. 修改登录与下载接口：成功登录和成功下载后尽力写入审计事件；失败操作不记录。
4. 新增管理员审计接口，并将当前成员与角色安全地加入已认证摘要响应。
5. 修改简体中文界面：登录时选择姓名；仅管理员显示并按需加载访问日志。
6. 增加认证、权限、审计写入和接口行为测试，并运行测试、代码检查、生产构建及明文密码扫描。
7. 将管理员密码仅转换为加盐哈希写入托管密钥，提交并同步源码，发布新版本，验证线上权限边界。
